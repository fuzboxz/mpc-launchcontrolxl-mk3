## Modes

- **DAW Mixer** (device mode 1): rows 1/2 = Send 1/2 per track, row 3 = Pan.
  Page up/down switches the send bank (1+2 / 3+4).
- **DAW Control** (device mode 2): rows 1/2 = MPC Q-Links 0-15, script-driven
  via qlinks `Touch` + `Twist`; native routing (`AddInfiniteCCToQLink`) is
  disabled pending the direction probe — see `reports/00-FINAL-TRIAGE.md` §5.
  Row 3 = global parameters (tempo, swing, quantize
  strength, quantize division, metronome, loop, automation filter, master
  volume); Page up/down cycles row 3 global/track, Shift+Page walks plugin presets.
- **Custom modes** (device modes 6-29): the surface belongs to the device; the
  script keeps transport and navigation alive and shows the mode on screen.

## Faders and pickup

Faders write `normalTracks[bank+col].Volume`. On load and on every bank move the
script pushes each track's volume to the device (CC 5-12 on MIDI ch 16) so the
hardware pickup can suppress jumps, and arms a software pickup that ignores
movement until the fader reaches or crosses the track's value.

## Journal

Every action logs a line through `print`, prefixed `LaunchControlXL3:`.
Read it with:

```sh
journalctl -u acvs -o cat --no-pager | grep LaunchControlXL3
```

## Guards

Project-scoped actions refuse to run while no project is loaded or a dialog
owns the UI (`engineMode.CurrentPopup` is not `No Popup`). Each refusal logs
once. Missing APIs (Q-Link mapping, sequencer, tracks) disable their surface
and never crash the host app.
